## Language Scope Decision

**v1 is English-only.** Tweets are filtered/flagged by language but not deleted.

**Rationale**:
- ~90% of SpotifyCares tweets are English
- Multilingual evaluation requires language-specific models and evaluation sets
- Flagging allows future multilingual extension without re-running preprocessing

**How to enable multilingual**: Set `detect_lang: true` in config or pass `--detect-lang` to `prepare_data.py`.

## Resolution Type Classification

Brand replies are heuristically classified into:

| Type | Retrieval-Worthy | Description |
|------|-----------------|-------------|
| `troubleshooting` | ✅ | "Try restarting the app..." |
| `informational` | ✅ | "You can find that at spotify.com/..." |
| `clarification_request` | ✅ | "Can you tell us which device...?" |
| `private_escalation` | ❌ | "Please DM us so we can..." |
| `acknowledgement` | ❌ | "Thanks!", "Ok", "Got it" |
| `closing` | ❌ | "Let us know if you need anything!" |
| `other` | ❌ | Unclassified |

Only `retrieval_worthy=True` interactions enter the FAISS index.

## Golden Set Warning

⚠️ `spotify_golden_set_annotation_template_250.csv` uses **weak keyword-heuristic labels**.
- `gold_intent_verified: False` means the label has NOT been manually verified
- Do NOT report evaluation metrics using unverified labels
- Manually review and set `gold_intent_verified: True` before final evaluation
- `should_escalate` and `escalation_reason` columns must be filled manually

## Data Leakage Prevention

1. Golden set tweet IDs are excluded from the FAISS index at build time
2. Golden set is never used for classifier training or threshold selection
3. Deterministic seed (42) used for all sampling
